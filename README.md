# kicad-mylib

This is my personal KiCad library, symbols, footprints, and 3D models organized my own way, so I stop redrawing the same resistor for the tenth time. It follows a simple naming convention (see `LIBRARY_CONVENTION.md`) so parts stay consistent and easy to find as the library grows.

Right now it covers the basics: resistors, capacitors, inductors, diodes, and transistors, plus a first ICs and modules entry, with matching footprints and STEP/WRL 3D models. Some footprints and 3D models were vendored from the official KiCad libraries (credit and license details in `NOTICE.md`); everything else is made or curated by me.

Still a work in progress, so expect gaps, and expect it to improve over time as I add more categories and clean things up.
